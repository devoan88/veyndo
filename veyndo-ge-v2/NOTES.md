# NOTES — veyndo-ge-v2

სტატიკური ქართული+ინგლისური ვებსტუდიო საიტი (`data-ka` / `data-en`). გერმანული არ არის.

## დროებითი გადაწყვეტილებები
- **ბრენდი:** „კონტური / Konturi“ — სამუშაო სახელი. მფლობელმა უნდა აირჩიოს Veyndo ან ახალი.
- **დომენი:** კოდში `config.js` → `domain: https://veyndo.ge` (დომენი ჯერ შეიძლება არ იყოს რეგისტრირებული).
- **ფასები:** ცხრილი პლაცეჰოლდერია.
- **პორტფოლიო:** ცარიელი — მხოლოდ რეალური ნამუშევრები შევა.

