# Veyndo App: პროდუქტის სპეციფიკაცია (v1, ავსტრია)

ეს დოკუმენტი აღწერს, **რას აკეთებს აპი** პირველ ვერსიაში. კოდი ამ დოკუმენტის მიხედვით აიწყობა.
აპის ტექსტები გერმანულადაა (ავსტრიული კლიენტებისთვის), დოკუმენტი ქართულად.

## 2. ეკრანები

### საჯარო (შესვლის გარეშე)
1. **Startseite** `veyndo.at/app`: რას აკეთებს აპი, 3 ტარიფი, „Kostenlos starten“.
2. **Anmelden / Registrieren**: ელფოსტით (ჯადოსნური ბმული ელფოსტაზე, პაროლის გარეშე) ან Google-ით.
3. **საჯარო პროფილი** `{slug}.veyndo.at`: ბიზნესის გვერდი (იხ. §4).
4. **AGB, Datenschutz, Impressum** Veyndo-სთვის.

### კლიენტის (შესვლის შემდეგ)
5. **Onboarding** (პირველი შესვლისას, 4 ნაბიჯი):
   1. დარგის არჩევა → შაბლონი ავსებს ყველაფერს;
   2. სახელი, მისამართი, ტელეფონი;
   3. მომსახურება და ფასები, სამუშაო საათები;
   4. ფოტოები (არასავალდებულო) → „Veröffentlichen“.
6. **Editor**: ყველა ველის შეცვლა, მარჯვნივ (ტელეფონზე ღილაკით) ცოცხალი გადახედვა.
7. **Tarif**: ტარიფის არჩევა → Stripe Checkout → დაბრუნება აპში.
8. **Dashboard**: სტატისტიკა 30 დღისთვის, შემდეგი ნაბიჯების სია, QR-კოდის ჩამოტვირთვა, ღილაკი „Veyndo erledigt es für Sie“.
9. **Konto**: ელფოსტა, ინვოისები (Stripe Customer Portal), გამოწერის გაუქმება, ანგარიშის წაშლა.

### ადმინის
10. **Admin**: კლიენტების სია (ფილტრი ტარიფით და დარგით), MRR (ყოველთვიური შემოსავალი), ახალი რეგისტრაციები, მოთხოვნები „Veyndo erledigt es für Sie“-დან.

## 4. საჯარო პროფილის შემადგენლობა (ზემოდან ქვემოთ)

1. საფარის ფოტო (ან დარგის ფერი), ბიზნესის სახელი, დარგი, უბანი.
2. ღილაკები: **Anrufen**, **WhatsApp**, **Route** (Google Maps-ის ბმული).
3. „Über uns“: 1–3 წინადადება.
4. „Leistungen“: სახელი, ფასი (Profil+), ხანგრძლივობა (არასავალდებულო).
5. „Öffnungszeiten“: დღეების მიხედვით; დღეს ღია/დახურულია.
6. ფოტოების გალერეა (Profil+).
7. „Kontakt“: მისამართი, ტელეფონი, ელფოსტა, სოციალური ქსელები.
8. **Impressum** (კლიენტი ავსებს; ავსტრიაში სავალდებულოა) და ბმული Datenschutz-ზე.
9. ქვედა ზოლი: „Erstellt mit Veyndo“ (ტარიფის მიხედვით).

**Google-ისთვის:** თითოეულ გვერდს აქვს სათაური, აღწერა და `LocalBusiness` სტრუქტურირებული მონაცემები (schema.org), რომ Google-მა მისამართი, საათები და ფასები სწორად წაიკითხოს.

## 5. მისამართის (slug) წესები

- ავტომატურად სახელიდან: „Nagelstudio Lena“ → `nagelstudio-lena`.
- ä → ae, ö → oe, ü → ue, ß → ss; მხოლოდ a–z, 0–9 და „-“; 3–40 სიმბოლო.
- უნიკალური. თუ დაკავებულია, ემატება უბანი: `nagelstudio-lena-1070`.
- **დაცული სახელები** (არ შეიძლება): app, www, admin, api, mail, veyndo, hilfe, support, login, status, blog.
- შეცვლა შეიძლება თვეში ერთხელ; ძველი მისამართი 90 დღე ახალზე გადაამისამართებს.
